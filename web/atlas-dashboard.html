    How data reaches the dashboard

    1. The simulator generates an event with an ID and a time.
    2. The API validates it and confirms it in a persistent queue.
    3. The publisher inserts batches into ClickHouse.
    4. The views combine the most recent positions and statuses.
    5. The browser queries every two seconds.

    The query frequency does not guarantee a two-second delay. Position age measures what is actually visible. One ClickHouse node and one API; the queue is not a replica.
